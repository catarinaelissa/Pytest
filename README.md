# Pytest
Testes Automatizados com Pytest


A PARAMETRIZAÇÃO PERMITE CRIAR VÁRIAS POSSIBILIDADES DE TESTE EM UMA MESMA FUNÇÃO POR MEIO DE TUPLAS 
PERMITINDO QUE VÁRIOS TESTES OCORRAM SIMULTANEAMENTE


UTILIZAR FIXTURE É MAIS ÚTIL QUANDO PRECISA REUTILIZAR UMA DETERMINADA BASE DE DADOS ORIGINAL COM OS MESMOS VALORES 
ATÉ O FIM DO TESTE SEM QUE OUTRAS OPERAÇÕES TENHAM REALIZADO ALTERAÇÕES.


FALHAR É UM TESTE QUE DEU ERRO NA OPERAÇÃO E O SKIP VAI SER UM TESTE QUE PRECISA SER IGNORADO TEMPORARIAMENTE 
PORQUE PRECISA DE OUTRO RECURSO QUE SEM ELE VAI FALHAR
